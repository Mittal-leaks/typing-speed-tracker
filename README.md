# Terminal-Based Typing Speed Tracker

A lightweight, zero-dependency console application built using Python to evaluate a user's typing speed and character-level accuracy.

## Features
- Random sentence generation using core Python arrays.
- High-precision runtime recording via the native `time` module.
- Bounded algorithmic accuracy checking to prevent index overflow crashes.

## How To Run
1. Make sure you have Python 3 installed on your machine.
2. Download `typing_tracker.py` from this repository.
3. Open your terminal or command prompt, navigate to the folder, and run:
   ```bash
   python typing_tracker.py
   ```
